FAQ

常见问题

关于授权、凭据与数据边界的几个直接回答。

buffTerm 是免费的吗？

是。buffTerm 以 MIT 协议开源，代码在 GitHub，下载安装免费；使用 AI 能力需要你自己配置模型平台的 API Key。

SSH 凭据存在哪里？

只存本机 SQLite，使用 AES-256-GCM 加密；主密钥保存在系统钥匙串。把数据库文件单独拷走无法解密凭据。

AI 会看到我的密码吗？

不会。SSH 密码、私钥口令与 API Key 不会进入模型上下文，命令输出在发送给模型前还会过滤密钥、口令等敏感信息。AI 对话与巡检内容会发送到你配置的模型平台。

支持哪些模型？

任意 OpenAI 兼容接口，例如 DeepSeek、Qwen、Kimi、OpenAI 与本地 Ollama。单平台可配置多个模型，并按上下文窗口切换。

macOS 提示“未签名”怎么办？

当前 macOS 版本未做 Apple 公证。首次打开时在“系统设置 → 隐私与安全性”中允许即可；这不影响凭据加密与本地存储。

支持 Linux 吗？

目前官方安装包为 macOS 与 Windows，尚未提供 Linux 官方安装包。

MCP 服务会不会暴露到公网？

不会。服务只监听 127.0.0.1，使用随机 token 认证，支持 token 轮换与三档权限（只读 / 管控 / 全部放行）。
